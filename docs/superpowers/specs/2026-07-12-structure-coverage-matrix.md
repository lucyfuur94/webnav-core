# Structure coverage matrix — web UI patterns × the five-axis inference model

**Date:** 2026-07-12 · **Status:** Phase 1 deliverable of the future-proof program · **Model under test:** `2026-07-10-structure-inference-design.md` (five axes + affordance kinds + fold + shell + value-domain refusal)
**Inputs:** three censuses (WAI-ARIA APG patterns · 7 component libraries: MUI/AntD/Carbon/Bootstrap/Polaris/SLDS/Radix-shadcn · page archetypes incl. GOV.UK), deduplicated; divergence notes kept inline.

**Totals: 90 rows — 66 COVERED · 19 PARTIAL · 5 GAP.** (`gaps` = GAP-verdict rows; cross-cutting core-work items that leave their host rows PARTIAL are ranked in the GAPS section too, marked *cross-cutting*.)

## Legend

- **A1** settledness (readiness-gated landings; redirect chains → aliases) · **A2** ARIA declaration (dialog/alertdialog/menu/listbox/tooltip = transient overlay; option/menuitem\* = value domain; landmarks = shell) · **A3** cross-page variance (≥80% pages ⇒ shell record) · **A4** cross-visit/instance variance (k-of-n template core; URL-template × structural-template joint identity; 1 landing ⇒ `provisional`) · **A5** within-page repetition (two-level subtree signatures; ≥2 same-shape siblings ⇒ `scope:'row'`/widget fold; overlay value domains never stored).
- **effects** = recorded action-effect diffs decide affordance kind (URL change ⇒ navigate; added subtree ⇒ reveal; in-place change ⇒ mutate). **fp/near** = elementFp `{role,name,near}`. **commit** = needs-classification protocol (#5a, never auto-fired). **needs** = declared preconditions (creds, prior steps). **readiness** = `classifyReadiness` retry.
- **OQ1/2/3** = the three known open questions: main-landmark identity scoping · container-scoped folding for nested value domains · unnamed icon-only content.
- Verdict rubric (ruthless): **COVERED** = maps correctly with existing mechanisms. **PARTIAL** = a named aspect degrades, and the degradation is honest (provisional / needsFix / escalation / omission — never a wrong map). **GAP** = needs new core work or a pattern pack, or would produce a wrong map.
